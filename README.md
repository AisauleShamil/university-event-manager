# University Event Manager

A desktop application built with C# (.NET) and MS SQL Server designed to streamline event scheduling, speaker management, and user registrations in an academic environment.

## Key Features

* **Event Management:** Create, view, and organize campus events.
* **Speaker Tracking:** Manage event speakers and assign them to scheduled sessions.
* **Database Integration:** Relational MS SQL Server schema to manage records efficiently.
* **Modular UI:** Built using Windows Forms with separated UI components and underlying data models.

## Tech Stack

* **Language:** C#
* **Framework:** .NET Framework (Windows Forms)
* **Database:** Microsoft SQL Server
* **IDE:** Visual Studio 2022

## Project Structure

* `UniversityEventManager.sln` — Visual Studio Solution file
* `UniversityEventManager/` — Application source code (`.cs`), forms, and models
* `UniversityEventManager/database.sql` — SQL setup script for database tables
